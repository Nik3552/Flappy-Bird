# Flappy-Bird

Flappy Bird Clone
A classic Flappy Bird game clone built with HTML, CSS, and JavaScript, utilizing jQuery for smooth event handling and animations.

This lightweight browser game challenges players to navigate the bird through endless pipes, testing reflexes and precision. The project demonstrates DOM manipulation, game logic implementation, and responsive controls in a clean, easy-to-understand codebase — perfect for learning or showcasing frontend skills.

Features:

Responsive controls powered by jQuery

Simple and clean UI with CSS styling

Real-time collision detection and scoring system

Fully playable in any modern browser
